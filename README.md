# Покана за Рим

Статичен сайт (HTML, CSS, JS, без build). Целият текст, датите и часовете са в обекта `CONFIG` в началото на `script.js`.

## Пускане в GitHub Pages

1. Слей клона `ccr-a4767f0f-1gwoej` в `main` (или в Pages избери директно този клон).
2. GitHub → Settings → Pages → Build and deployment → Source: **Deploy from a branch**.
3. Branch: `main`, папка `/ (root)` → Save.
4. След 1–2 минути сайтът е на `https://orlinstefanov.github.io/proposal-/`.

Локално: `python3 -m http.server` в тази папка.
